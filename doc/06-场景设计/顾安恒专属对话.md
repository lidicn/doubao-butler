# 顾安恒专属对话 · 安防专员链路

> 版本：v2.1 Phase 2 | 更新：2026-09-16

## 一、设计目标

在豆包 APP 顾安恒对话里，用户说"看看客厅摄像头" → 管家自动取摄像头画面 → doubao2api 视觉分析 → 截图+分析结果推送到顾安恒对话。

**不产生双重回复**：豆包网页端自己回复固定话术，管家只推送分析结果。

## 三、完整链路

```
用户在豆包APP顾安恒对话发："看看客厅摄像头"
        │
        ▼
doubao2api 轮询到新消息 → POST webhook /api/doubao/webhook
        │
        ▼
webhook 判断 role_id == gu_anheng
        │
        ▼
检测用户输入关键词（摄像头/监控/看看/画面/起居室/客厅/书房）
        │
        ▼
匹配房间名 → go2rtc 流名映射
        │
        ▼
go2rtc 取帧: http://192.168.2.200:1984/api/frame.jpeg?src=cam_客厅
        │
        ▼
notifier.push_image() → 下载帧 → base64 → /v1/images/analyses
        │
        ▼
分析结果 + 截图推送到顾安恒对话
```

## 五、关键技术点

### 5.1 视觉分析端点

**必须用 `/v1/images/analyses`**，不是 `/v1/chat/completions`。后者对 image_url 返回 500。

`notifier.push_image()` 内部自动把 URL 从 `/chat/completions` 替换为 `/images/analyses`，并支持：
- `keep_conversation: True` — 保留对话上下文
- `conversation_id` — 推送到指定对话

### 5.2 避免双重回复

webhook 收到顾安恒消息后，**不调 doubao2api**（避免再产生一条回复），直接走关键词触发 → 取帧 → 推送。

豆包网页端自己会根据长期记忆里的操作说明书回复固定话术。

### 5.3 顾安恒操作说明书（长期记忆）

已通过 `POST /api/roles/gu_anheng/push` 推送：

```
【操作说明书 - 必须严格遵守】
当主人说"看看客厅摄像头" → 回复：好的，正在为你查看客厅摄像头，请稍等。【CAMERA_REQUEST:客厅】
当主人说"看看起居室摄像头" → 回复：好的，正在为你查看起居室摄像头，请稍等。【CAMERA_REQUEST:起居室】
...
```

### 5.4 硬编码兜底

`doubao_webhook.py` 中硬编码了：
```python
GU_ANHENG_CID = "38440360274498562"
if conversation_id == GU_ANHENG_CID:
    role_id = "gu_anheng"
```
不依赖 role_state.json 映射。
