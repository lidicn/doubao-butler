## 一、已完成的接口

### 1. Ask 聆听模式（P0 ✅ 已完成）

**接口：**
```http
POST /api/ask/listen
Content-Type: application/json

{
  "duration": 30,
  "room": "客厅"
}
```

**行为：**
- 进入聆听模式后，**不需要唤醒词**，直接听写用户语音
- 听写结果通过 MQTT 发布到 `tv/livingroom/wake`，格式同现有 voice_command
- duration 秒后自动退出聆听模式
- 如果已经在聆听模式，重复调用刷新 duration

**响应：**
```json
{
  "ok": true,
  "message": "ask listen started, duration=30s"
}
```

---

### 2. Ask 停止聆听（P0 ✅ 已完成）

**接口：**
```http
POST /api/ask/stop
```

**行为：** 立即退出聆听模式，恢复唤醒词监听。

**响应：**

## 二、已修复的问题

### 4. 换台接口编码问题（P0 ✅ 已确认）

**问题：** 豆包管家调用 `/api/zap` 时，中文频道名变成乱码（????），导致换台失败。

**原因：** 豆包管家发送 JSON body 时没有用 UTF-8 编码。

**解决方案：** 豆包管家调用换台接口时，必须：
1. Content-Type: `application/json; charset=utf-8`
2. Body 用 UTF-8 编码

**测试验证：**
```bash
curl -X POST http://192.168.2.200:8090/api/zap \
  -H "Content-Type: application/json; charset=utf-8" \
  -d '{"channel": "中央一台"}'
```

**响应：**
```json
{
  "ok": true,
  "channel": "中央一台",
  "channel_no": 21,
  "method": "adb_digits",
  "zap_time_ms": 4271
}
```

## 三、完整 Ask 交互流程（已实现）

```
管家 LLM 生成问句："要不要打开电视？"
  ↓
管家调 TVPilot /api/tts 播报问句
  ↓
TVPilot 播完 TTS
  ↓
管家调 TVPilot /api/ask/beep（播提示音）
  ↓
管家调 TVPilot /api/ask/listen（30秒免唤醒听写）
  ↓
用户说"好" → TVPilot MQTT 发布 voice_command
  ↓
管家收到回答 → 执行 tv_launch_app → TTS 确认
```

## 六、注意事项

### 1. 编码问题（重要！）
- 所有 HTTP POST 请求的 JSON body **必须用 UTF-8 编码**
- Content-Type 必须包含 `charset=utf-8`
- 否则中文会变成乱码（????），导致换台失败

### 2. 换台架构
- **播放**：电信 IPTV 原生播放器（`com.android.smart.terminal.iptv`）
- **换台**：TVPilot 通过 ADB 发数字键到 IPTV
- **mytv**：后台保活，不参与播放和换台

### 3. 频道名映射
- 传入频道名称（如"中央一台"、"湖南卫视"）
- TVPilot 自动映射到 IPTV 频道号
- 完整频道列表见 `/api/channels`
