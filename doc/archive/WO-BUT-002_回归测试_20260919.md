## 四项修复验证

### ① UNKNOWN 重播上限
- 第一次 UNKNOWN → 重播 prompt，`pending["unknown_retry"] = 1`
- 第二次 UNKNOWN → 走 NO（cancel），不再重播
- 代码位置：`butler/core/dialog.py:278-290`

### ② 草稿 generation
- `SkillCreator._generation` 计数器，每次 `create_draft()` 自增
- 草稿携带 `generation` 字段，`get_pending()` 校验代际，跨代自动作废
- 代码位置：`butler/skills/creator.py:111,124-126,202-210`

### ③ 删除重复 dialog.py
- 已删除 `butler/dialog.py`（根级旧副本）
- 保留 `butler/core/dialog.py`（app.py 唯一引用）
- 容器内验证：`import butler.dialog` → `ImportError: No module named 'butler.dialog'`
- 容器内验证：`import butler.core.dialog as d; print(d.__file__)` → `/app/butler/core/dialog.py`
