### v1.5 — 轻 Agent 统一工具层（当前版本）
> 主题：所有入口统一走 LLM function calling，不再依赖文本标签解析

**核心架构**：
```
入口（手机APP / DeskPilot / TVPilot / ESP32）
  → Context Builder（系统prompt+对话历史+记忆+当前状态）
  → LLM（doubao2api function calling）
  → Tool Executor（按工具名路由）
  → 结果反馈（LLM组织自然语言回复）
```

**工具注册表**：
| 工具域 | 工具 | 执行方 | 状态 |
|---|---|---|---|
| home_device | 开/关灯、空调、电视、风扇 | HA API | ✅ 已有（标签解析，待迁移） |
| scene | 观影/睡眠/晨起/离家 | 场景引擎 | ✅ 已有 |
| query | 设备状态查询 | HA API | ✅ 已有 |
| weather | 实时天气/预报 | 彩云天气 `192.168.2.200:3000` | 🔲 新增 |
| ma | 成员档案/在场查询 | MA `192.168.2.200:8086` | 🔲 对接 |
| computer_action | 开浏览器/截图/锁屏/音量/音乐 | DeskPilot | 🔲 对接 |
| tv_action | 切台/搜索播放/回桌面 | TVPilot | ✅ ReAct已接，待统一 |
| memory | 记住/忘掉/对账 | 记忆系统 | ✅ 对话内指令已有 |

**Context Builder 注入内容**：
- 系统层：角色定位 + 工具列表
- 状态层：当前时间、谁在家（MA）、关键设备状态
- 记忆层：相关事实
- 对话层：最近10轮历史

**里程碑**：
- M1：工具注册表 + Executor 骨架，迁移 HA 设备控制到 function calling
- M2：对接彩云天气（/api/weather, /api/realtime）
- M3：对接 MA（成员档案读取 + 在场状态查询）
- M4：对接 DeskPilot（computer_action 工具）
- M5：统一入口（DeskPilot/TVPilot 直接调 /api/chat，不自己接LLM）

### v2.0 — 自进化 Agent（长期）
- 从成功/失败轨迹自动学习
- 技能自动生成与优化
- 长期记忆与个性化
- **验收方式**：用户联调 + 长期观察

#### v2.0 子方向：AI 编程自我迭代
- 豆包写 Python/JS/JSON → webhook 读取 → 写入隔离目录 → 审计 → 部署
- 风险控制：隔离目录（/app/butler/user_scripts/）+ 二次审计 LLM + 回滚机制
- 起步：先从 JSON 配置（新设备映射、触发器规则）开始，不直接写核心 Python
- 验证小实验：让豆包写一条新设备映射 JSON → webhook 解析 → 重载配置
