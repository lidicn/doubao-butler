## 四、协作体系与操作手册

### 4.1 工单下发流程

1. PM 在 `E:\NAS\doubao-butler\board\handoffs\` 创建工单（格式：`YYYYMMDD_NNN_标题.md`）
2. 同时复制一份到对应项目的 `docs/` 目录（TP: `E:\NAS\TVPilot\docs\`，DP: `E:\NAS\DeskPilot\docs\`）
3. 通过 DeskPilot PM 管道发送消息通知 TP/DP：
   ```powershell
   Invoke-RestMethod -Uri "http://192.168.2.201:8765/api/v1/pm/send" `
     -Method Post -Headers @{ "Authorization" = "Bearer deskpilot-dev-token-123456" } `
     -ContentType "application/json" `
     -Body (@{ target="TP"; message="新工单：xxx，请查看 docs 目录"; press_enter=$true } | ConvertTo-Json)
   ```
4. TP/DP 接手后通过看板 API 上报状态（进行中/已完成）
5. 完成后在工单上标注状态 + 写回复单

### 4.2 任务状态上报 API

TP/DP 在任务开始/完成时调用管家看板 API：

```bash
# 接手任务
curl -X POST http://192.168.2.200:8095/api/taskboard/report \
  -H "Authorization: Bearer <redacted>" \
  -d '{"task_id":"TASK-20260908-001","agent":"TP","status":"in_progress","note":"开始开发"}'

# 完成任务
curl -X POST http://192.168.2.200:8095/api/taskboard/report \
  -H "Authorization: Bearer <redacted>" \
  -d '{"task_id":"TASK-20260908-001","agent":"TP","status":"completed","note":"已完成，659 tests passed"}'
```

### 4.3 消息分级

- **紧急**：通过 DeskPilot PM 管道直接发送（会打断当前对话，相当于插话）
- **不紧急**：下发工单文件，等 TP/DP 当前任务完成后查看
- **决策请示**：通过 PWA 看板推送 A/B/C 选项，用户在 PWA 上选择

### 4.4 交接单规范

- **格式**：`YYYYMMDD_NNN_标题.md`
- **双副本**：`board/handoffs/` + 对应项目 `docs/`
- **状态标注**：进行中 / 已完成 / 已接受 / 已拒绝
- **回复单**：TP/DP 完成后写回复单到 `board/replies/`
- **完成的交接单**：标注状态 + 追加实现记录
