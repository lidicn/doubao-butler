# 豆包管家 用户手册

> 版本：v1.6 | 更新：2026-09-12
> 定位：家庭全屋智能中枢——手机APP/PWA/小爱语音/WebUI 统一入口

---

## 一、系统概览

```
你说的话
  ↓
多个入口：手机豆包APP / PWA语音按钮 / WebUI管家页 / 小爱音箱 / DeskPilot / TVPilot
  ↓
Koin 轻 Agent 引擎
  ├─ 第一层：快速路由（关键词匹配，0 LLM，毫秒级）
  │   └─ 天气 / 时间 / 谁在家 / 自动沉淀的规则 / 设备别名
  ├─ 第二层：LLM Function Calling（模糊意图 → 调工具）
  └─ 第三层：自进化轨迹记录（agent_traces 表）
  ↓
执行层：HA设备控制 / TTS播报 / TV推送 / Bark推送 / 微信推送
```

## 二、WebUI 功能页面

WebUI 地址：`http://192.168.2.200:8095`
默认账号：`admin`

### 📊 概览（🏠）
- 系统状态总览（管家状态、各连接点状态灯）
- 最近对话记录
- 快捷操作入口

### 🤖 管家（butler_chat）
- WebUI 内置聊天窗口
- 直接输入指令，走 Koin Agent
- 调试用：看 LLM 回复、工具调用轨迹

### 📣 推送（push）
- **电视通知推送**：标题+内容，选类型（info/warning/error）
- **TTS 语音播报**：可加语音、调音量、暂停媒体
- **推送历史**：重发/删除

### 💬 对话（dialog）
- 最近对话记录查看
- 对话状态调试（冷却、免打扰、连续对话模式）

### 🎭 人格（persona）
- 系统提示词编辑
- 成员个性化语气（大佬/凯文/爱美丽）

### 👥 角色（roles）
- 8个角色管理（butler/lidicn/kevin/emily + 3个个人助理）
- 每个角色绑定一个豆包APP对话ID
- 长期记忆投喂（当前版/更新版，手动按键投喂）
- 角色测试/推送

### 🧩 技能（skills）
- 技能列表管理（启用/禁用/删除）
- 技能编辑（触发词、提示词、输出通道）
- 技能沙箱测试
- 技能版本管理/回滚

### 📋 指令（commands）
- 外部设备（DeskPilot/TVPilot）下发的指令队列
- 待处理指令数量提醒
- 接受/完成/失败/取消操作

### ⚡ 触发器（triggers）
- 自动化触发器管理
- 触发器模板
- 触发历史记录

### 🪪 画像（profile）
- 家庭成员画像（大佬/凯文/爱美丽）
- LLM 自动整理功能：贴一段话 → 自动提取结构化信息

### 🧠 记忆（memory）
- **本地记忆库**：查看/删除
- **语义记忆**：MA（memory-agent）查询
- **成员指纹**：各角色记忆概览
- **事实提取**：从对话中自动提取事实，审核后投喂
- **投喂历史**：查看每次投喂记录

### 🔄 自进化（evolution）
- **技能自进化**：
  - 自进化模式（被动/半自动/主动）
  - 统计卡片（待处理建议/已执行/失败/学习数据点）
  - 改进建议列表，一键确认执行
  - 对话轨迹回放
  - 自进化历史

- **Koin 快速路由**：
  - 当前快速路由规则列表（启用/禁用/删除）
  - 分析候选（从 LLM 轨迹自动提取高频操作）
  - 一键采纳候选规则

- **设备别名学习**：
  - 自动学习：你说"打开客厅灯"，我记住"客厅灯"对应哪个设备
  - 别名列表（关键词 → entity_id，出现次数）
  - 错误别名手动删除

### 🔌 设备（devices）
- HA 设备管理（按域筛选：light/climate/media_player 等）
- 房间映射配置
- 双通道发声设置（小爱自带 TTS / edge-tts 音色）
- 耳朵传感器映射（小爱对话输入）

### 📡 通道（channels）
- **Bark 推送**：
  - 配置状态显示
  - 测试推送（标题/内容/级别/铃声可选）

- **小米/小爱音箱**：
  - 8台小爱设备列表
  - 房间映射 + 对话传感器状态
  - 绿色=已接耳朵，红色=未接

- **微信/iLink**：
  - 配置状态显示
  - 通道名称

### ⚙️ 设置（settings）
- TTS 设置（主引擎、音色、语速、音量）
- 唤醒与免打扰设置
- 数据目录说明

## 五、Koin 三层架构详解

### 第一层：快速路由（0 LLM，毫秒级）
匹配关键词直接执行，不调大模型。

内置规则：
- 问天气 → 直接查彩云天气API
- 问时间 → 直接返回当前时间
- 问谁在家 → 直接查在场状态

自动沉淀：
- 高频 LLM 路径 → 自动生成候选规则 → WebUI 确认后加入
- 设备别名 → 你说"客厅灯"我直接知道是哪个设备

### 第二层：LLM Function Calling
模糊意图理解，调工具完成。

可用工具：
- 设备控制（control_device）
- 天气查询（get_weather）
- 记忆查询（query_memory）
- 电视推送（push_to_tv）
- 摄像头分析（analyze_camera）
- 生成图片（generate_image）
- DeskPilot 桌面操作
- TVPilot 电视操作

### 第三层：自进化轨迹记录
所有 LLM 调用落库到 `agent_traces` 表，用于：
- 快速路由自动沉淀（M1）
- 设备别名学习（M2）
- 失败模式分析（M3）

## 六、记忆系统

### 记忆分层
1. **手机豆包APP长期记忆**：豆包官方长期记忆，跨对话保留
2. **管家本地记忆库**：`/app/data/` 下的 SQLite
3. **MA（memory-agent）**：独立容器，语义记忆存储

### 投喂方式
- **手动投喂**：WebUI 记忆页 → 事实提取 → 审核 → 一键投喂
- **设备说明书投喂**：一键恢复设备操作指令（存进豆包APP长期记忆）
- **记忆对账**：投喂前先问豆包"你还记得XX吗"，核对后再投喂

### 角色绑定
- 8个角色，每个角色绑定一个豆包APP对话ID
- 投喂时指定角色，只往对应对话里写
- 事实提取时自动标 target_role

## 九、API 接口（鉴权：Bearer <redacted>）

### Agent
- `POST /api/agent/chat` — 对话
- `GET /api/agent/traces` — 轨迹列表
- `GET /api/agent/fast-routes` — 快速路由列表
- `GET /api/agent/fast-routes/analyze` — 分析候选规则
- `POST /api/agent/fast-routes` — 添加规则
- `POST /api/agent/fast-routes/{id}` — 启用/禁用
- `DELETE /api/agent/fast-routes/{id}` — 删除
- `GET /api/agent/aliases` — 设备别名列表
- `DELETE /api/agent/aliases/{alias}` — 删除别名

### 记忆
- `GET /api/memory/local` — 本地记忆列表
- `GET /api/memory/semantic` — 语义记忆
- `POST /api/memory/facts/extract/run` — 运行事实提取
- `POST /api/memory/facts/{id}/approve` — 批准事实
- `POST /api/memory/feed/{role_id}` — 投喂到指定角色

### 推送
- `POST /api/bark/push` — Bark 推送
- `GET /api/bark/status` — Bark 状态
- `POST /api/notify` — 电视推送

### 设备
- `GET /api/devices` — 设备列表
- `POST /api/devices` — 添加/更新设备
- `GET /api/ha/devices` — HA 设备列表

### 系统
- `GET /api/health` — 健康检查
- `GET /api/status` — 系统状态
- `GET /api/version` — 版本号
