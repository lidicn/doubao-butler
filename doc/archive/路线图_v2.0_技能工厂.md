# 豆包管家 v2.0 — 技能工厂（Skill Factory）

> 创建：2026-09-15
> 前置：v1.9 Koin Action【智动】已完成
> 核心目标：让 LLM / 外部 agent 用自然语言创建、编辑、管理技能，技能和 Koin Action 共用同一底座。

## 背景

v1.9 完成了 Koin Action（定时条件任务），但技能系统和 Koin Action 是两套独立实现：
- 技能系统：`butler/skills/`，通过 trigger 触发，支持多种 engine
- Koin Action：`butler/core/cron_task.py`，cron 定时触发，HTTP API + JSONPath 条件

用户讨论结论：**技能和 Action 应该共用同一底座**，LLM 可以编写两者。

## v2.0 主题：技能工厂

### Phase 1：统一底座（P0，3天）

1. **Skill-Action 统一 Schema** ✅
   - 创建 `cron_task` 引擎（`butler/skills/engines/cron_task/`）
   - 引擎委托给 `rt.cron_task_executor.execute_task()` 执行 HTTP+条件+动作
   - schema.py 扩展：`brain.engine=cron_task` 时保留 api_id/condition/message_template
   - 支持 hour_local 时区条件透传
   - rain_reminder 已迁移到新引擎，不再双重调度

2. **LLM 编写技能** ✅
   - creator.py 添加 koin_action 模板
   - ENGINE_GUIDE 加入 cron_task 引擎说明（api_id/condition/message_template）
   - LLM prompt 加入已注册 API 列表和 hour_local 条件格式
   - 预览方法支持 cron_task 类型显示 API/条件/文案
   - 验证：通过 /api/skills 创建 koin_action 技能 → 执行 → HTTP+条件+动作全链路通过
   - 用户通过对话说："帮我创建一个技能：每天早上7点查天气，如果下雨就提醒我带伞"
   - LLM 自动生成技能 JSON，调用创建 API
   - 内置模板库：天气提醒、设备定时开关、新闻播报、邮件摘要等

3. **WebUI 技能创建向导** ✅
   - 自然语言输入框 → LLM 生成技能 JSON → 预览 → 确认创建
   - API: `POST /api/skills/natural-create`
   - 技能列表显示健康度（成功率/最近执行状态）
   - 一键启用/禁用/编辑/删除

### Phase 2：MCP Server（P1，2天）✅

4. **MCP Server** ✅
   - 新增 5 个工具：list_skills / create_skill / delete_skill / get_skill_health / list_cron_apis
   - 总计 11 个 MCP 工具，外部 agent（autoflow/Claude Desktop）可通过 MCP 连接管家
   - 已验证 initialize + tools/list 全部返回正确

5. **技能市场**
   - 系统内置模板技能列表
   - 用户一键安装模板技能
   - 支持从社区导入技能 JSON

### Phase 3：自进化闭环（P2，3天）✅

6. **失败模式记录** ✅
   - 每次执行失败自动记录到 `failure_patterns.jsonl`
   - 连续失败时 Bark 告警附带修复建议（规则-based）
   - API: `GET /api/cron_task/failures?skill_id=xxx`

7. **使用数据反哺** ✅
   - 健康度 API 已有成功率/连续失败统计
   - MCP `get_skill_health` 已暴露给外部 agent
   - 长期不用的技能可通过 `list_skills` 过滤识别

## 技术要点

- **不碰设备控制核心**：技能工厂只做"创建/管理/调度"，设备控制仍走 simple_rules / doubao2api
- **安全隔离**：技能执行的 HTTP 调用仍受 SSRF 白名单 + Secret Vault 保护
- **向后兼容**：现有技能 JSON 格式不变，只是增加 engine=cron_task 的支持

## 验收标准

1. 用户通过对话说一句话 → LLM 自动创建可用的定时任务技能
2. 创建后可在 WebUI 看到、编辑、启用/禁用
3. MCP 客户端能列出技能、触发技能
4. 现有 rain_reminder 技能不回归
