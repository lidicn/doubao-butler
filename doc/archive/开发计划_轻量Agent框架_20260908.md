## 一、背景与目标

豆包管家当前是"单轮反射"（调一个接口→返回→结束）。v1.1 目标：升级为**可观察 ReAct 闭环**（Thought→Action→Observation→Adjust），与 TVPilot v0.2 工具层联调，实现多步电视控制（换台 / 搜索播放电影）。

**验收场景**：
1. 换台："换到湖南卫视" → zap → current/foreground 验证；
2. 搜索播放："在电视上播放《流浪地球2》" → launch_app 飞牛TV → 搜索 → 中文输入 → 回车 → 播放；
3. 逃生：异常时 `KEYCODE_HOME` 恢复。

1. 3 个联调场景全部通过，轨迹可在 API 回放；
