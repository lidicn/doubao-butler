> 创建时间：2026-09-06

> 开发者：豆包管家开发者

## 一、项目背景

### 1.1 使用场景

用户对小爱音箱说：**"我想听《三体》"**，系统自动：
1. 解析语音指令，识别书名《三体》
2. 在 NAS 上找到对应的 EPUB 文件
3. 解析 EPUB，提取正文文本
4. 调用 edge-tts 合成语音
5. 通过小爱音箱播放

### 1.2 已有基建（无需重复开发）

| 能力 | 现状 | 位置 |
|------|------|------|
| 小爱音箱语音接入 | ✅ 已有 | 豆包管家对话链路 |
| edge-tts 语音合成 | ✅ 已有 | butler/integrations/tts.py |
| 小爱音箱播放控制 | ✅ 已有 | butler/integrations/xiaomi.py |
| 技能引擎框架 | ✅ 已有 | butler/skills/ |
| NAS 文件访问 | ✅ 已有 | 容器已挂载 NAS 目录 |

### 1.3 为什么不独立建项目

- 核心链路 100% 复用豆包管家（语音入口→TTS→音箱控制）
- 独立项目等于重写已有链路，维护成本高
- 豆包管家技能引擎天然支持这种扩展
- 项目体量小，独立部署不划算

### 3.2 EPUB 解析方案

**推荐库：`ebooklib`**（轻量，纯 Python）

```python
# 安装依赖
pip install ebooklib

# 核心解析逻辑
from ebooklib import epub
from ebooklib.utils import debug

def parse_epub(filepath):
    """解析 EPUB，返回章节列表"""
    book = epub.read_epub(filepath)
    chapters = []
    for item in book.get_items_of_type(9):  # 9 = ITEM_DOCUMENT
        # 提取 HTML 中的纯文本
        soup = BeautifulSoup(item.get_content(), 'html.parser')
        title = soup.find(['h1', 'h2', 'h3'])
        text = soup.get_text()
        chapters.append({
            'title': title.text if title else '未命名章节',
            'content': text,
            'index': len(chapters)
        })
    return chapters
```

**备选方案**：如果 ebooklib 兼容性不好，用 `zipfile` 直接解压 EPUB（EPUB 本质是 ZIP），手动解析 HTML。

### 3.4 播放流程

```
用户说"我想听三体"
    ↓
技能匹配意图 → play_book(book_name="三体")
    ↓
library.py 查找书籍 → 找到 /path/to/三体.epub
    ↓
epub_parser.py 解析 → 章节列表
    ↓
progress.py 读取进度 → 上次听到第3章
    ↓
player.py 播放第3章
    ├── 调用 edge-tts 合成当前段落
    ├── 调用小爱音箱 API 播放
    ├── 一段播完 → 自动下一段
    └── 一章播完 → 自动下一章 + 更新进度
```

### 3.6 书架扫描

```python
# 扫描 NAS 上的 EPUB 目录
BOOKS_DIR = "/nas/books"  # 容器内路径

def scan_library():
    """扫描 EPUB 文件，建立索引"""
    books = []
    for root, dirs, files in os.walk(BOOKS_DIR):
        for f in files:
            if f.endswith('.epub'):
                book_id = hashlib.md5(f.encode()).hexdigest()[:8]
                books.append({
                    'id': book_id,
                    'name': f.replace('.epub', ''),
                    'path': os.path.join(root, f),
                    'size': os.path.getsize(os.path.join(root, f))
                })
    # 保存到 library.json
    save_library(books)
    return books
```

## 四、关键技术点

### 4.1 长文本分段播放

EPUB 一章可能很长，edge-tts 单次合成有长度限制。需要：
1. 按段落/句子切分文本
2. 逐段合成 + 播放
3. 维护播放队列，播完一段自动下一段

### 4.2 播放中断恢复

用户说"暂停"后，需要记住当前播放到哪一段，"继续"时从该段开始。

### 4.3 书名模糊匹配

用户可能说"三体"、"三体系列"、"三体第一部"，需要模糊匹配到实际文件名。

### 4.4 TTS 缓存

同一本书同一段落可能反复听，建议缓存合成好的音频文件，避免重复调用 edge-tts。

## 五、配置项

在 butler 的配置文件中添加：

```yaml
skills:
  audiobook:
    enabled: true
    books_dir: "/nas/books"           # EPUB 文件目录（容器内路径）
    default_speaker: "客厅小爱"        # 默认播放音箱
    tts_voice: "zh-CN-XiaoxiaoNeural" # TTS 音色
    auto_next_chapter: true           # 自动播放下一章
    cache_audio: true                 # 缓存合成的音频
    cache_dir: "/data/audiobook/cache"
```

## 七、风险与注意事项

1. **EPUB 格式兼容性**：不同来源的 EPUB 结构差异大，需要多测试几本
2. **edge-tts 限流**：大量段落合成可能触发限流，建议加缓存和间隔
3. **小爱音箱播放队列**：确认小爱音箱 API 是否支持连续播放多段音频
4. **内存占用**：大 EPUB 解析可能占用较多内存，建议按需解析章节而非一次性全解析
