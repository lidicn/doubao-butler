## 五、已知限制与后续计划

### 5.1 当前限制

1. **DeskPilot 截图超时**：桌面代理在线（pid 26448），但截图 API 耗时>15s 超时。待 DP v2.8 截图优化后解决。多模态工具代码逻辑已验证正确。
2. **多模态 token 消耗**：默认 brief 模式（<100字），截图 480px 宽。detailed 模式消耗较大，非必要不使用。
3. **M4 多模态缓存**：P2 优化，同一张截图不重复分析。当前未实现，每次调用都重新截图+分析。
4. **M9 LLM 重写建议**：低质量技能发现 API 已存在，但 LLM 自动生成重写建议尚未实现。当前需人工分析。
5. **技能市场分享**：导入/导出已实现，但技能分享（生成分享链接/二维码）尚未实现。当前通过导出 JSON 文件手动分享。

### 5.2 后续版本（v1.4+）

- v1.4：全屋联动增强（多设备联动/场景模板/自动化建议）
- v2.0：自进化 Agent（从轨迹自动学习/技能自动生成优化/长期记忆）
