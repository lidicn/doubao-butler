## 三、D17：SSRF 护栏的 fail-closed 方向（补丁副本实测行为）

护栏已拦四类内网形态（127.0.0.1/localhost/.local/::1 全拦，实测 5/5）。要定的取舍只有一条：

> **外部域名在 DNS 临时解析失败时也被拒**（判据原文：「解析不了就无法证明它不是内网」）。

- **A. 维持 fail-closed（推荐 ⭐⭐⭐⭐⭐）**：注册外网 API 是一次性、可重试的操作，被拒的代价＝重试一次；放行的代价＝攻击者用「暂时解析得到、解析时变内网」这类 DNS 重绑定窗口打洞。风险几星：维持现状 ≈ 1 星（用户侧偶发重试）。
- B. 解析失败放行（⭐）：把上面对价反过来付。
- C. 解析失败时白名单例外（⭐⭐）：多一张要人维护的表，收益只有 B 的一半。
