## 本次做了什么

1. E 仓 `main` 推到 GitHub（SSH）：GitHub `main` 从 `36f8558` → `52a2d6c`（含修三条 DB-001/002/003 + 关闭 speak 每日预算限额）。

3. 装 DB 宿主 cron：`host_check_update.sh`（每 5 分钟）、`host_update.sh`（每分钟）。
4. `.env` 设 `SELF_UPDATE_ENABLED=true`、`UPDATE_REPO_URL=git@github.com:lidicn/doubao-butler.git`、`UPDATE_BRANCH=main`；`docker compose up -d --no-build --force-recreate` 重建后容器 healthy。

## 以后怎么用

- 在 E 盘改码、`git commit`、推 GitHub `main`（SSH）。
- WebUI「设置 → 自更新」点「检查更新」（宿主每 5 分钟出预览）→ 「填当前版本号 → 请求更新」→ 宿主 `host_update.sh` 落码。
- 注意：日常 `main` 只落码**不重启**；要让新代码生效，发 `v<主>.<次>` 版本 tag（自动重启）或手动 `docker restart doubao-butler`。
