```
├── 外扫/               # 外部扫描结果

├── DEV日志/            # 开发日志（按日期）
└── archive/            # 过时文档归档（只读，不删除）
```

## 文档规范

- 新文档放入对应分类目录，文件名含日期（`_YYYYMMDD`）
- 过时文档移入 `archive/`，不删除
- 接口文档需包含：端点、参数、返回值、错误码、示例
- 交接单需包含：背景、做什么、验收标准、联系方式
