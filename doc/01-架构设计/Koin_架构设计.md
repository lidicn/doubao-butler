# Koin 轻 Agent 架构设计

> 版本：v1.5 | 日期：2026-09-12
> 定位：豆包管家的统一大脑，所有入口的中枢推理层

---

## 一、三层架构

```
用户输入（手机APP / DP / TP / WebUI / PWA）
  ↓
第一层：快速路由（0 LLM，~100ms）
  │  关键词匹配 → 直接执行工具
  │  命中？→ 返回结果，结束
  ↓ 没命中
第二层：LLM Function Calling（~2-5s）
  │  Context Builder 注入上下文
  │  LLM 选择工具 → 执行 → 组织回复
  │  工具失败？→ 自动重试或换工具
  ↓
第三层：自进化沉淀
     记录所有"LLM完成但快速路由未命中"的轨迹
     人工审核后 → 高频路径沉淀为新的快速路由规则
```

---

## 二、什么走快速路由（确定性操作）

| 用户说 | 调的工具 | 为什么不需要LLM |
|---|---|---|
| "今天天气怎么样" | get_weather | 关键词明确，返回数据已格式化 |
| "明天会下雨吗" | get_weather(daily) | 同上 |
| "现在几点" | get_current_time | 关键词唯一 |
| "谁在家" | get_presence | 关键词唯一 |
| "打开书房空调" | control_device | 设备名+操作明确 |
| "关灯" | control_device | 固定动作 |
| "播放音乐" | desk_music_play / HA | 按source选目标 |

**判断标准**：意图确定 → 关键词能唯一映射到一个工具调用。

---

## 三、什么走 LLM（模糊/复杂意图）

| 用户说 | 为什么需要LLM |
|---|---|
| "书房太热了" | LLM要推理：开空调→制冷→26度 |
| "我有点无聊" | 模糊意图，LLM判断：放音乐？放电影？ |
| "帮我安排一下周五晚上" | 多步推理：晚托→到家时间→预热环境 |
| "凯文在玩什么游戏" | 需要结合记忆+设备状态推理 |
| "客厅灯光太暗了" | LLM判断：调亮哪个灯？多少亮度？ |

**判断标准**：意图模糊 / 需要多步推理 / 需要结合上下文判断 → LLM。

---

## 四、Source 上下文（区分调用端）

| source | 来自哪 | 默认操作目标 |
|---|---|---|
| webui | 管家WebUI | 全屋设备 |
| mobile | 手机APP/PWA | 全屋设备（客厅音箱为主） |
| dp | DeskPilot电脑端 | 电脑操作优先（音量/音乐/截图） |
| tv | TVPilot电视端 | 电视操作优先（切台/播放） |

同一个"播放音乐"：
- source=dp → desk_music_play（电脑上播）
- source=mobile → HA media_player（客厅音箱播）

## 五、自进化闭环

### 5.1 记录什么

每次"快速路由未命中 → LLM完成"的轨迹，记录：
- 用户原文
- LLM选了哪个工具
- 工具执行结果
- 最终回复
- 是否成功
- source（从哪来的）

### 5.2 怎么沉淀

1. **自动分析**（每天凌晨）：找出高频成功的 LLM 路径
   - "书房太热了" → 总是调 control_device（空调制冷26度）
   - "关灯" → 总是调 control_device
2. **人工审核**：WebUI 展示候选新规则，PM 一键确认
3. **沉淀为快速路由**：确认后加入关键词表
   - "太热/热了" → 快速路由到空调工具
   - "关灯" → 快速路由到灯工具

### 5.3 降级容错

- 快速路由命中但工具失败 → 自动降级走 LLM
- LLM 也失败 → Bark 推送告警

## 六、工具清单（Koin 可调度）

| 域 | 工具 | 执行方 |
|---|---|---|
| 查询 | get_current_time / get_weather / get_presence | 本地 |
| 设备控制 | control_device（灯/空调/电视/风扇） | HA API |
| 场景 | 观影/睡眠/晨起/离家 | 场景引擎 |
| 电脑 | desk_volume_set / desk_music_play / desk_screenshot | DeskPilot |
| 电视 | tv_launch_app / switch_channel | TVPilot |
| 记忆 | recall / remember | MA |
