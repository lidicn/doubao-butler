## 二、鉴权到底挂在哪一层（机制原文）

1. **没有全局鉴权中间件，没有按路径前缀匹配的 gate**。全树（`butler/`，排除 `__pycache__`）实跑：
   ```
   grep -rn "app.middleware\|BaseHTTPMiddleware\|Middleware(" api/ app.py presence/ timeseries/ modes/ ha_tools/ proactive/ guard/ triggers/ mcp/ integrations/ | grep -v __pycache__
   ```
   **命中 = 1 行，且是 CORS**（分母：上述 10 个扫描目录/文件全部 .py）。app.py:732-746 原文：
   ```python
   app = Starlette(
       routes=routes,

   ```
   无 `dependencies=[...]`（`grep -n dependencies api/*.py app.py` = 0 命中；分母 = 34 个文件）。
2. **鉴权是逐 handler 手工调用** `butler/api/deps.py` 的 `guard()`（:299-303）：
   ```python
   def guard(request: Request):
       """无鉴权返回 err(...)。配合路由使用。"""
       if not check_auth(request):
           return err("未登录", 401)
       return None
   ```
   `check_auth()`（deps.py:224-259）认三种凭证：会话 cookie `butler_auth`、`Bearer <web_password>`（`ALLOW_PASSWORD_AS_BEARER` 未关时）、具名服务钥匙 `BUTLER_SERVICE_TOKENS`（deps.py:148-158）。**fail-closed**：未配 `BUTLER_WEB_USER` 时默认全拒（:229-232），除非显式开 `allow_no_auth`（:219-221，WO-ME-204）。
3. `command_routes.py` 有一层薄包装 `_guard()`（:19-21，内部转调 deps.guard），9 条路由经它生效——计入 401 基线。
4. `audiobook_routes.py:57` 直接 `if not check_auth(request): return err("未登录", 401)` ——仅 `/api/audiobook/play` 一条。

⇒ **推论（换锁窗口的坑的根源）**：鉴权不在中间件 ⇒ 「一条路由是否要口令」只能逐 handler 数，文档清单不可信 ⇒ 本单按源码逐条枚举。
