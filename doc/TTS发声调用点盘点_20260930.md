## 1. 扫描方法（分母写明白，别人可复跑）

两组模式，同一棵树（排除 `butler/_debug/`）：

```
A: grep -rn --include="*.py" -e "play_xiaomi_url_once(" -e "tts_play_url(" \
      -e "intelligent_speaker(" -e "play_url(" butler            → 25 命中
B: grep -rn --include="*.py" -e "tts_speak(" butler | grep -v "_debug" | grep -v "def tts_speak"   → 4 命中
```

合计 29 命中，扣 5 条非业务出口 ⇒ **24 处业务级发声出口**：

| 扣除项 | 为什么扣 |
|---|---|
| `butler/tts/playback_queue.py:77` | per-device 队列工人自己的出口 = 锁持有者，唯一"合法终点" |
| `butler/integrations/ha.py:342` | `notify_text` 内部转 `intelligent_speaker`，驱动层 |
| `butler/integrations/ha.py:412` | 公开方法转 `_play_xiaomi_url_once` |
| `butler/integrations/ha.py:414` | 函数定义本身 |
| `butler/notify/router.py:5` | 文档串里的路径名，不是调用 |

入队侧另数一次（不同模式，不与上表混算）：`grep -rn "enqueue_tts" butler --include="*.py" | grep -v "def enqueue_tts"` ⇒ **4 个调用点**；`grep -rn "\.speak(" butler --include="*.py"` ⇒ 业务级 `rt.tts.speak(...)` **4 处**（其余是 `speaker.speak(item)` 的队列内部调用与文档串）。

## 2. 三档路径（"旁路"的实际形状）

合成侧是干净的：三种后端（`edge_tts` / `nowvoice_tts` / `kokoro`）**只在 `butler/tts/manager.py:120-124` 被分发**，全仓没有第二处合成入口。脏的是播放出口。

| 档 | 路径 | 经过哪些闸 | 调用点 |
|---|---|---|---|
| **一档（双层）** | `enqueue_tts()` → `TTSQueue`（优先级 / 静默时段 / 熔断 / 过载 / trace_id + **全局顺序播放锁** `queue.py:216`、`:383`）→ `TTSManagerSpeaker.speak`（`adapter.py:55`）→ `TTSManager.speak`（`manager.py:183`）→ `PlaybackQueue.enqueue`（`manager.py:198` 注入，**per-device 串行** + 2s 间隔） | 2 层 | 4 处：`core/briefing.py:214`、`core/dialog.py:670`、`app.py:728`、`bus/inbox.py:192` |
| **二档（只过 manager）** | `rt.tts.speak(...)` 直接调 | 只有 per-device 串行；⛔ 丢优先级、静默时段、熔断、过载、trace_id、全局顺序 | 4 处：`proactive/engine.py:302`、`timeseries/anomaly.py:371`、`af_bridge.py:151`、`morning/routine.py:207` |
| **三档（真旁路）** | 自己合成 + 自己投射，两个队列都不进 | ⛔ 0 层 | **24 处**（第 3 节） |

## 4. 收口时要一并处理的两个"不是 bug 但会误导"的点

1. **`helper.enqueue_tts` 在队列未初始化时返回 False 并只打一条 warning**（`helper.py:23-25`）——调用方大多不看返回值 ⇒ 静默不响。§13.4 那次简报缺 import 就是被这种"吞掉"掩盖的同类。
2. **两套串行语义不同名**：`TTSQueue.play_lock`（`queue.py:216` / `:383`）是**全局一次一条**；`PlaybackQueue` 是**每设备一次一条、设备间并发**。日志和文档里都只说"队列"，不统一命名，下次还会有人以为过了一个就过了另一个。
