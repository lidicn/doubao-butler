## 3. 量出来的三条事实

### 3.1 鉴权故障会被读成「家里没人」——这条本窗修掉了

改前链条（`core/agent.py`）：`pr = await client.get(...)` 之后**没有状态码检查**，直接 `pdata = pr.json()`；只要 body 是 JSON 而 `ok` 不为真，就走 `else` 分支把 **「【当前在家】最近30分钟未识别到家庭成员。」** 写进 system prompt 交给大模型。工具链 `get_presence` 同型（回「最近30分钟没有识别到家庭成员」）。

⇒ 缺钥匙、MA 挂了、MA 换地址、MA 改鉴权，四种故障都表现为"这个家现在没人"。这是当年那些"没人却说话／说话说不清谁在家"类排查里最难归因的一型：它不留错误日志。

改后：`_butler_fetch()` 先看 `status_code >= 400` → `{"ok": False, "error": "HTTP 401"}`；body 里 `ok=false` 也单独判出来；`agent.py` 在 `ok=False` 时**不加那行**并 `logger.warning`；工具侧回「在场查询失败：HTTP 401」。缺凭据则在出网**之前**拦下（0 次请求）。
一处诚实标注：FastAPI 默认 401 回 `{"detail": …}` 属"JSON 且无 ok"这一类——这个 body 形状我**没有现采**（⛔ 我无凭据去撞真 401），标「推断-未现采」。但新逻辑不依赖它：判据是状态码，两种形状都走 failure 分支。

### 3.2 空的 Basic 凭据真的会被发到线上（读数，不是我推的）

本窗当场探针 `/tmp/probe_empty_basic_1001.py`（本机 httpx 0.23.3 + `MockTransport`，⛔ 不触网）：`auth=("", "")` 落到 wire 上是 `Authorization: Basic Og==`，被 mock 判 401。

⇒ 改前 `analyze_room_live()` 在 `MEMORY_AGENT_USER/PASS` 缺失时，每调用一次就发一次空凭据；现网 camera_vlm 引擎在调这条路（`skills/engines/camera_vlm/engine.py:112`）。
改后：缺任一侧 → 0 次请求 + `{"ok": False, "error": "MA 凭据未配置：面 basic 缺 MEMORY_AGENT_USER/PASS"}`。调用方 `_ma_analyze` 原有 `ok=False` 分支照旧 ⇒ 没有新增失败形态，只是不再往外发空钥匙。

### 3.3 app_token 那一路是双重死路

`add_memory_via_app_token`／`list_memories_via_app_token` 全仓 `grep`（含 `tests/`）**0 调用者**，且 `MEMORY_AGENT_APP_TOKEN` 盘上与活容器都无 ⇒ v1.5 P0-5「记忆统一入库」既没人调、又没钥匙。它属于记忆投喂闸（红线区），本窗只登记不接线；要接得先裁「谁把写手切到这条路」。
