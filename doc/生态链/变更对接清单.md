## §0 四类变更与通用前置（先定性质，再谈顺序）

| 类别 | 定义 | 一句话风险 |
|---|---|---|
| **甲 · 改地址** | IP、端口、URL 前缀变了 | 对方手里那张"电话号码表"是硬编码的，它不会自己更新，只会一直重试到超时 |
| **乙 · 改主题 / 路由名** | MQTT 主题、HTTP 路径、动作名变了 | MQTT 是**哑总线**：没人订也不报错，消息静静消失 ⇒ 最容易变成"看起来一切正常" |
| **丙 · 改口令 / 凭据** | 值变了（含用户名、token、密钥） | 一把钥匙常开多把锁；**改一处 = 没改**（见凭据台账 §1 八个组） |
| **丁 · 改字段 / 返回形状** | 键名、类型、默认值、状态码、包络变了 | 双方字段名对得上但**语义**对不上，是本次五断点里最难发现的一类 |

## §6 一句话
