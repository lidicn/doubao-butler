## §0 口径、算法与分母（先自报，后面所有「N 处 / 0 命中」只在这个分母内成立）

### 0.1 指纹怎么算（可复跑，且不会回显值）

```bash
# 取某行里的第一个带引号字面量 → 只输出长度与 md5 前 8 位
sed -Np <文件> | tr "'\"" "\n\n" | sed -n 2p | awk '{print length($0)}'
sed -Np <文件> | tr "'\"" "\n\n" | sed -n 2p | printf %s | md5sum | cut -c1-8
# 全仓找同值位点（-F 定值匹配，只留 路径:行号，不留内容）
grep -rnIF --exclude-dir=node_modules --exclude-dir=.git --exclude-dir=models \
  --exclude-dir=__pycache__ --exclude-dir=build_tmp --exclude-dir=build -F "$V" <树…> | cut -d: -f1,2
```
为什么用 md5 前缀：两把钥匙是不是同一把，只看前 8 位就够判定；值本身一旦写进这张表，这张表就变成了新的泄露点。

## §4 八条交叉发现（决定"按什么顺序改"）

1. **用户名 == 口令**（组 A，`.env:8` = `:9`）⇒ 改口令时若顺手也把用户名改了，等于同时改了"账号"和"密码"，前端 13 处里有的写的是 Bearer、有的写的是登录表单，两类都要跟。
2. **组 A 的 13 处在对外下发的 JS 里** ⇒ 任何浏览器"查看源码"即可拿走。**按已泄露处理**，不是"要不要改"而是"必须改"。已在 `WO-ME-206`（P0，在做）。
3. **一把 MQTT 口令印在四份同名文档里**（`MA接口标准_v1.0_生态共享.md`，3 份含值、1 份不含 ⇒ 四份已不一致）。
4. **TVPilot 的两把钥匙没有免重建通道**（源码进镜像 + compose 无 `environment:`），且 adbkey 也在镜像层 ⇒ 这是"改口令"成本最高的一个仓，**必须和其它改动合并进同一次重建窗口**。
5. **DeskPilot 的 token 已进入免鉴权可下载的 `dist`** ⇒ 只换值不重建前端，泄露不撤销。
6. **Arcface 两条 MQTT 初始化入口凭据来源不一致**（AppConfig vs 硬编码）⇒ 同一 App 内"一半新一半旧"。
7. **三把 47 字符 MA 钥匙互不相同**（`088a438f` / `a7c62813` / `bc682941`）、**两把 51 字符 LLM 钥匙互不相同**（`d2f849ab` / `63ff9734`）⇒ 长度相同的钥匙必须靠 md5 前缀区分，不能靠肉眼。
8. **两套 MQTT 凭据并存**（组 B 五方里四方用一把，DeskPilot 自己一把）⇒ 换总线口令要按两套分别执行。
