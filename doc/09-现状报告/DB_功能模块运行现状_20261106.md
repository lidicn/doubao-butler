| 问题 | 实证 |
|---|---|
| README 索引严重滞后 | README 只收录 5 份"核心文档"，336 份里绝大多数未登记；"最新审计报告"仍指向 `20260926`，而 `审计报告/` 已有到第二十一轮 |
| 路线图双版本并存 | `00-路线图` 同时有 `..._v2.4.md` 与 `..._v2.5_DCD版.md`；README 仍写 v2.4"唯一权威" |

| 审计件双轨 | `doc/审计报告/`（30+41）与 `doc/05-测试验收/`（2 份 0926 审计）各放一套 |

## 三、WebUI 与后端的对应关系

### 3.1 规模对照（实测）

- WebUI 视图 **19 个**：overview、butler_chat、push、dialog、persona、roles、skills、koin、commands、triggers、debug、profile、memory、evolution、devices、channels、perception、settings、logs
- 独立页面脚本 **13 个**（`static/js/pages/`），其余 6 个内联在 `index.html`
- 前端实际调用 `/api` 路径 **113 条**
- 后端 `Route` 定义 `/api` 路径 **249 条**
- **后端有、前端零引用：143 条**

### 3.2 结论：WebUI 只覆盖约一半后端能力

后端 143 条无 WebUI 入口的能力，按域归类：

| 域 | 代表端点 | 影响 |
|---|---|---|
| 有声书 | `/api/audiobook/{books,play,pause,next,status…}` | 后端完整，WebUI 完全无入口 |
| 决策 | `/api/decision/{create,list,*/vote,*/cancel}` | 决策引擎只能靠 API/外部调 |
| 主动问询 | `/api/proactive/{ask,list,pending,scenes,budget,*/answer}` | 无 UI 可看预算/待答/场景 |
| 模式 | `/api/modes/{current,switch,rules,history}` | 家庭模式无界面开关 |
| 在场 | `/api/presence/{snapshot,users,rooms,events,where/*}` | 感知页只覆盖一部分 |
| 时序 | `/api/timeseries/{anomalies,appliance/runtime,modes}` | 异常/用电无入口 |
| 安全/护栏 | `/api/security/*`、`/api/guard/*` | 安全告警无 UI |
| 任务板 | `/api/task/{board,list,*/status}` | 任务板无 UI |
| 通知中心 | `/api/notification/{list,*/read,read_all}` | 有推送无消息中心 |
| 技能扩展 | `/api/templates/*`、`/api/perf/*`、`/api/collab/*`、`/api/conflict/*` | 模板/性能/协作无 UI |
| iLink 微信 | `/api/ilink/*` | 无 UI |
| 审计/健康 | `/api/triggers/{health,audit,sources}` | 部分只在 debug 页 |

另外：前端引用的端点**基本都有后端**（差集里剩下的都是注释/模板字符串噪声，例如 `api.js` 里 `update_routes.py` 是注释、`index.html` 的 `/api/mcp</code>` 是说明文本），**不存在"前端点了 404"的整条缺失**——问题在"后端能力没做 UI"，不是"UI 调不存在的接口"。

## 四、已确认的逻辑问题（带证据）

### 4.1 早晚播报"AI 胡言乱语"——四条证据链

**(1) 人格文件根本没进容器**
生产日志（2026-11-05 22:00）：
```
WARNING [butler.core.briefing] persona file not found:
  [Errno 2] No such file or directory: '/app/doc/briefing_persona.md'
```
`briefing.py:42` 用 `doc/briefing_persona.md` 作系统人格，但部署只挂 `butler/ data/ tts/`，**`doc/` 不在容器里** → 回退成一句"你是这个家的管家。"，家庭成员/称呼/风格约束全部丢失。这是"胡言乱语"的第一因。

**(2) 新闻源已坏，但 prompt 仍要求"挑一条新闻"**
```
WARNING [butler.core.briefing] news: 0, message='Attempt to decode JSON with
  unexpected mimetype: text/html; charset=utf-8', url=URL('https://60s.viki.moe/v2/60s')
```
`_fetch_news()` 解析失败返回 `[]`，而 prompt 规则 3 仍写"新闻里挑一条大佬可能感兴趣的"。数据没有、指令要有 → **LLM 只能编**。

**(3) 首调 LLM 偶发空响应，闸门只挡"空/短/失败"**
```
ERROR [butler.core.briefing] briefing LLM:
WARNING [butler.core.briefing] briefing degenerate, retry once: '简报失败：'
```
`_briefing_is_bad()` 只判 `空白/少于8字/无字母数字汉字/含"失败"`；**语义胡言（编新闻、编日程、编天气）不会被拦**，直接推 Bark + TTS。

**(4) 两条"报告技能"已隔离，定时腿空转**
生产日志：
```
WARNING trigger evening_report action skipped: skill=evening_report quarantined
WARNING trigger morning_report action skipped: skill=morning_report quarantined
```
隔离记录：
- `morning_report`：`2026-11-02 07:20`，原因"连续 3 次执行失败自动隔离"，`enabled:false`
- `evening_report`：`2026-10-29 21:30`，原因"24小时内执行超时 2 次"

⇒ 07:20 / 21:30 触发器每天空跑；真正出声的只剩 07:10 / 22:00 的 LLM 简报，而它的人格与数据都是残的。
