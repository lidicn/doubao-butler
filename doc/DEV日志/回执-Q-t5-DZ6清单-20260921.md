## 1 结论（六条，都在下面 §2 有对应读数）

1. **洞是真的，但只在 `_env` 这一类**：`_env()` 共 60 个调用点，其中 **33 个带非空默认**。只要环境里出现 `KEY=`（有键、空值），`os.environ.get(key, default)` 就不走 default 分支，拿到空串 ⇒ **默认被静默顶掉，且不报错**（base `:14-15`）。另 27 个 `_env()` 调用点本来就没默认值（空串是它的设计值），不在这条暴露面内。
2. **`_env_int`(9) / `_env_float`(3) 结构免疫**：空串进 `int()`/`float()` 抛 `ValueError`，被 `except (TypeError, ValueError)` 接住并回退默认（base `:18-22`、`:25-29`）⇒ 这 12 个键整列判「否」。
3. **`_env_bool`(3) 有另一个更强的洞**：`v = os.environ.get(key, "")` ⇒ **缺键与空串走同一条路**，两者都直接 `return False`，**`default=True` 永不可达**。全站唯一的 True 默认是 `TTS_CACHE_ENABLED`（`:258`）。⚠ 但这一版有下发物兜着：`docker-compose.yml:29` 与 `docker-compose.dev.yml:60` 都显式写了 `TTS_CACHE_ENABLED=true` ⇒ **此刻行为正确，风险在丢掉这两行时静默关缓存**（三层落点：代码默认＝坏、下发物＝补上的、配置＝未采）。另 `:37` 的 `return False if v == "" else False` 两分支同值＝死三元，作者本意应是 `return default`。
4. **四把凭据键不是静默空值，是启动崩**：`DOUBAO_API_KEY`(`:272-276`)、`DESKPILOT_API_TOKEN` + `TASK_REPORT_TOKEN`(`:278-284`)、`BUTLER_WEB_PASSWORD`(`:286-291`) 为空即 `raise RuntimeError`（WO-BUT-017/018/022）⇒ 这四行判「是（硬失败＝起不来）」而不是「未验」。⚠ 门只拦空串，**不拦弱值**（见 §3-2）。
5. **「读取点个数」不能按 PM 原口径数键名**：75 个键里只有 **4 个**的键名在 `config.py` 之外出现过 ⇒ 数键名会把 71 个活键判成死键。有效口径 = 点号 `settings.<属性名>` **加** `getattr(x, "<属性名>", …)` 动态读；**只数点号也会把 4 个鉴权键判成死键**（§2.2）。
6. **顺手量到（不在 DZ-6 问句内，一句话给安全线）：镜像盘 `.env` 30 把有值键里 12 把的取值与源码默认逐字节相同**（含 4 把 URL 键）⇒ "已设"不等于"覆盖了什么"；真覆盖只有 3 把（§2.8）。同一批读数里 `BUTLER_WEB_USER == BUTLER_WEB_PASSWORD` 为 **True**（只出布尔，值不外引）。

一句话交付物：**75 行主表（一行一键，五列）+ 三种助手各自的空串语义 + 判「是」26 条 / 判「否」14 条 / 判「未验」35 条 + 零消费 6 条与 getattr 救援 4 条**。

### 2.1 三种助手的空串语义（base 树行号；本轮所有源码字面量只报**长度/形状**，不报值）

| 助手 | 定义行 | 环境里出现 `KEY=`（空值）时发生什么 | 后果 |
|---|---|---|---|
| `_env` | `:14-15` | `get(key, default)` 因键存在而不取 default ⇒ 返回 `""`，`.strip()` 后仍是 `""` | **默认被顶掉，静默**（33 个非空默认键全部暴露） |
| `_env_int` | `:18-22` | `int("")` 抛 `ValueError` ⇒ `:22 return default` | 免疫（9 键判「否」） |
| `_env_float` | `:25-29` | `float("")` 同上 ⇒ `:29 return default` | 免疫（3 键判「否」） |
| `_env_bool` | `:32-38` | `get(key, "")` ⇒ **缺键与空串同路径**，命中 `:36` 的元组 ⇒ `:37 return False` | `default` **永不被读**；唯一 True 默认 `TTS_CACHE_ENABLED` 拿不到 |

### 2.2 读取点计数：三把尺对账（PM 原口径为何不成立）

| 尺子 | 口径 | 结果 |
