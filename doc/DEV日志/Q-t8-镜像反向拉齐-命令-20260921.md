## 2 执行序（窗口内口令线走完之后再跑）

```bash
TREE=/vol1/1000/docker/doubao-butler
MIR='E:/NAS/doubao-butler'
LIST='butler/logging_setup.py butler/api/tts_routes.py butler/api/pwa_chat_routes.py'

# A) 源侧取读格：md5 + 字节数 + 二进制 CR/CRLF（EOL 血统要跟着走，别只比 md5）
ssh -o BatchMode=yes lidicn@192.168.2.200 \
  "for p in $LIST; do printf '%s\t' \"\$p\"; md5sum \"\$TREE/\$p\" | cut -d' ' -f1; \
   wc -c < \"\$TREE/\$p\"; python3 -c \"import sys;d=open(sys.argv[1],'rb').read();print('CR',d.count(b'\\r'),'LF',d.count(b'\\n'))\" \"\$TREE/\$p\"; done" < /dev/null

# B) 被挤掉的镜像件先归档（**不用 .bak 后缀**，开发规范禁 .bak 堆积）
mkdir -p "$MIR/workorders/mirror-before-20260921"
for p in $LIST; do cp "$MIR/$p" "$MIR/workorders/mirror-before-20260921/$(echo $p | tr '/' '.')"; done
ls -1 "$MIR/workorders/mirror-before-20260921" | wc -l    # 期望 3

# C) base64 内联回灌（Q-t8 既有通道形状），逐文件当场核 md5 与 CR
for p in $LIST; do
  ssh -o BatchMode=yes lidicn@192.168.2.200 "base64 -w0 \"$TREE/$p\"" < /dev/null | tr -d '\n' | base64 -d > "$MIR/$p"
  printf '%s  mirror=%s  ' "$p" "$(md5sum "$MIR/$p" | cut -d' ' -f1)"
  python -c "d=open(r'$MIR/$p','rb').read();print('bytes',len(d),'CR',d.count(b'\r'))"
done
```

## 3 验收读数（三条齐全才算拉齐）

1. 步骤 C 每行 `mirror=` 的 32 位 md5 **逐字节等于** 步骤 A 的源侧 md5（不是「接近」）；
2. 每个文件落地后的 `CR` 计数 == 源侧 `CR` 计数（血统随源，别把 LF 渗进 CRLF 目标，反之亦然）；
3. `workorders/mirror-before-20260921/` 计数 = 3，且拉齐后**同一次交接里**通知 Q-t6 重打三个数基线。

## 4 与 Q-t6 的耦合（PM 裁定 ② 原文要求同批）

拉齐会改回归门分母：`tests/` 侧一旦有件进镜像/树，`import_errors 1→0`（`tests/test_logging_masking.py:6` 的 collection 期 ImportError 就是这类），`total` 亦可能变。
⇒ **拉齐与重打基线必须写同一条窗口回执**；只拉不重打 = 上一版的「三个数」作废而台账还挂着它。
