# 豆包管家 用户手册

> 版本：v1.8 | 更新：2026-09-14
> 定位：家庭全屋智能中枢——手机APP/PWA/小爱语音/WebUI 统一入口

---

## 一、系统概览

```
你说的话
  ↓
多个入口：手机豆包APP / PWA语音按钮 / WebUI管家页 / 小爱音箱 / DeskPilot / TVPilot
  ↓
Koin 轻 Agent 引擎
  ├─ 第一层：快速路由（关键词匹配，0 LLM，毫秒级）
  │   └─ 天气 / 时间 / 谁在家 / 自动沉淀的规则 / 设备别名
  ├─ 第二层：LLM Function Calling（模糊意图 → 调工具）
  └─ 第三层：自进化轨迹记录（agent_traces 表）
  ↓
感知引擎（v1.7 新增）
  ├─ 事件流监听（人体/门窗/设备状态）
  ├─ 规则引擎（场景识别）
  ├─ 状态推断（位置/活动/谁在家）
  └─ 安全监控（门窗未关/异常能耗/紧急报警）
  ↓
执行层：HA设备控制 / TTS播报 / TV推送 / Bark推送 / 微信推送
```

## 二、WebUI 功能页面

WebUI 地址：`http://192.168.2.200:8095`
默认账号：`admin`

### 📊 概览（🏠）
- 系统状态总览（管家状态、各连接点状态灯）
- 最近对话记录
- 快捷操作入口

### 🤖 管家（butler_chat）
- WebUI 内置聊天窗口
- 直接输入指令，走 Koin Agent
- 调试用：看 LLM 回复、工具调用轨迹

### 🏠 家庭状态（state）
- 谁在家（人脸识别结果）
- 每个人当前在哪个房间
- 当前活动推断
- 今天活动时间线

### 📡 事件流（events）
- 实时事件流查看器
- 事件类型筛选（人脸/传感器/设备/语音）
- 事件历史查询

### 📣 推送（push）
- **电视通知推送**：标题+内容，选类型
- **TTS 语音播报**：可加语音、调音量、暂停媒体
- **推送历史**：重发/删除

### 💬 对话（dialog）
- 最近对话记录查看
- 对话状态调试（冷却、免打扰、连续对话模式）

### 🧠 记忆（memory）
- 记忆事实列表（习惯/偏好/作息）
- 审核待投喂的事实
- 投喂状态追踪

### 🎭 人格（persona）
- SOUL + USER + MEMORY 三份人格定义
- 人格版本历史（可回退）
- v1.7 新增：自动生成人格草稿

### ⚡ 技能（skills）
- 技能列表（已安装/已禁用）
- 技能执行记录
- 熔断器状态
- 自进化建议审核

### 📈 自进化（self_evolve）
- 学习数据点统计
- Koin 自进化轨迹（LLM 完成的轨迹）
- 技能自进化建议

### ⚙️ 配置（config）
- 系统配置编辑
- MQTT / LLM / TTS 配置
- 家庭成员管理

### 🛡️ 通道（channels）
- 微信 Bot 状态
- Bark 推送测试
- iLink 状态
- 小米 miio 状态

## 三、核心功能

### 3.1 语音对话

**入口**：
- 手机豆包 APP（直接对话）
- 小爱音箱（喊"豆包管家"唤醒）
- WebUI 管家页（文字输入）
- PWA 语音按钮（手机浏览器）

**支持的指令**：
- 设备控制："打开书房空调"、"关灯"
- 信息查询："今天天气"、"谁在家"
- 模糊意图："书房太热了"（LLM 自动开空调）
- 主动对话：管家主动找你说话

### 3.2 主动感知（v1.7 新增）

**事件源**：
- 人脸识别（TV 端 ArcFace）
- 人体传感器（HA）
- 设备状态变化（开关灯/开空调）
- 语音对话历史

**场景识别**：
- 进入书房工作
- 人员移动轨迹
- 入睡 / 起床
- 离家 / 回家
- 凯文玩 Xbox

**主动动作**：
- 不打扰模式（识别到工作/睡眠）
- 主动提醒（门窗未关/异常能耗）
- 早晚简报（7:10 早报 / 22:00 晚报）

### 3.3 记忆系统

**自动提取**：
- 对话结束后自动提取事实
- 分类：习惯 / 偏好 / 家庭 / 事件
- 置信度评分

**审核流程**：
1. 提取 → pending
2. WebUI 审核 → approved / rejected
3. 投喂到豆包 APP 长期记忆
4. 检测变更 → 标记 changed → 重新投喂

**角色**：
- `butler`：豆包管家（系统级）
- `lidicn`：爸爸
- `kevin`：儿子
- `emily`：女儿

### 3.4 早晚简报（v1.7 新增）

**早报**：每天 7:10
- 天气 + 体感
- 今日日程
- overnight 异常事件
- 个性化提醒（根据家庭成员状态）

**晚报**：每天 22:00
- 今日能耗
- 明天天气
- 安全检查（门窗是否都关了）

**人格驱动**：
- SOUL + USER + MEMORY 三份人格定义
- 模拟真人阅读报告，自己选重点
- 改写成口语化播报

### 3.5 安全监控（v1.7 新增）

**确定性规则**（不依赖 LLM）：
- 门窗未关提醒（离家时）
- 异常能耗提醒（空调开了但没人）
- 烟雾/水浸报警（直接推送 Bark）

## 四、TTS 播报

**引擎优先级**：
1. NowVoice（拟人化，首选）
2. EdgeTTS（稳定，次选）
3. Kokoro（本地离线）
4. Bark（兜底推送）

**播放通道**：
- 电视打开 → TV 端 TTS Player
- 电视关闭 → 小爱音箱 TTS
- 语音中断 → 停止当前播放

## 五、API 接口

### 认证
- WebUI：Session Cookie + 用户名密码
- Webhook：X-Webhook-Token Header
- MQTT：Username + Password

### 核心端点
- `GET /api/health` — 健康检查
- `GET /api/login/status` — 登录状态
- `GET /api/events/recent?minutes=60` — 最近事件流
- `GET /api/state/current` — 当前家庭状态
- `POST /api/doubao/webhook` — 豆包 Webhook

详细 API 文档：`/docs`
