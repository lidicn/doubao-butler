# doubao-butler 发布清单

每次改代码后，按此清单逐项检查再重启。

## 提交前必做

- [ ] **跑闸门**：`bash scripts/pre_deploy_check.sh`
  - 全树 245 个 .py 文件语法检查通过
  - 无 `"ok" in r` 子串误判
  - 无死副本

- [ ] **改了 JS/CSS？** → 递增 index.html 里的 `?v=N`
  - 改哪个文件就 bump 哪个的版本号
  - 不改前端就不用动

## 提交后必做

- [ ] `git push origin HEAD:refs/heads/main`（引用写全，禁 --force）
- [ ] `docker restart doubao-butler`
- [ ] 等 15 秒
- [ ] `curl -s http://localhost:8095/api/health` 返回 `{"ok":true}`
- [ ] `docker inspect -f '{{.State.Health.Status}}' doubao-butler` = `healthy`

## 禁止事项

- 禁止 `docker build`（bind mount 改代码即生效）
- 禁止 `git add -A`（只 add 修改的文件）
- 禁止改 `.gates.toml` 或 healthcheck 参数（调大超时 = 假绿）
- 禁止在 `async def` 里写同步 `requests.get` / `urllib.request.urlopen`
- 禁止用 `"ok" in r` 子串判定成功（用 `r.startswith("ok")`）
