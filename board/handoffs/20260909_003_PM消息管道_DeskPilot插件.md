## 一、背景与原因

当前 PM（豆包管家）给 TP/DP 发消息的方式是：
1. 管家容器调用 `http://192.168.2.201:18766/send`（独立 Python 转发服务 pm_forwarder.py）
2. 转发服务调用 `pm_send_to_pm.py`（ctypes 操作桌面：激活豆包窗口 → Ctrl+1/2/3 切对话 → 剪贴板粘贴 → Ctrl+V → 回车）

**问题**：
- 独立 Python 脚本需要手动启动，重启电脑后丢失
- 脚本分散在 `C:\tools\`，不便于管理和升级
- 没有集成到 DeskPilot 服务的生命周期管理
- 之前已开工单 20260908_004 要求集成，但需要更明确的插件化方案

**目标**：把 PM 消息管道做成 DeskPilot 插件，持久化在 DeskPilot 服务上运行，PM 通过 DeskPilot API 发送消息即可。

## 二、具体需求

### 2.1 插件架构

在 DeskPilot 中新增 `pm_messenger` 插件（或模块），包含：

| 组件 | 说明 |
|------|------|
| **API 端点** | `POST /api/v1/pm/send` — 接收 PM 发来的消息，转发到豆包对话 |
| **消息发送器** | 封装当前 pm_send_to_pm.py 的逻辑（ctypes 操作桌面） |
| **会话管理** | 支持指定目标对话：PM（Ctrl+1）、TP（Ctrl+2）、DP（Ctrl+3） |
| **健康检查** | `GET /api/v1/pm/health` — 返回插件状态、豆包窗口是否找到、最近发送记录 |
| **审计日志** | 记录每次发送的目标、内容摘要、时间、结果（成功/失败） |

### 2.2 API 定义

**发送消息**
```
POST /api/v1/pm/send
Headers: Authorization: Bearer <deskpilot-token>
Body: {
  "target": "PM" | "TP" | "DP",    // 目标对话，必填
  "message": "消息内容",             // 消息文本，必填，UTF-8
  "press_enter": true                // 是否按回车发送，默认 true
}
Response: {
  "ok": true,
  "target": "TP",
  "message_length": 128,
  "timestamp": "2026-09-09T12:00:00"
}
```

**健康检查**
```
GET /api/v1/pm/health
Response: {
  "ok": true,
  "doubao_window_found": true,
  "last_send_time": "2026-09-09T11:55:00",
  "total_sent": 42,
  "total_failed": 3
}
```

### 2.3 消息发送器实现

复用当前 `C:\tools\pm_send_to_pm.py` 的核心逻辑：
1. 查找豆包窗口（标题含"豆包"即可，不要求含"PM"）
2. 激活窗口（SetForegroundWindow）
3. 按 Ctrl+1/2/3 切换到目标对话
4. 清空剪贴板 → 设置剪贴板内容（UTF-8 中文）
5. Ctrl+V 粘贴
6. 按回车发送（如果 press_enter=true）

**注意事项**：
- 必须在用户会话（Session 1）中运行，不能在 Session 0 服务中直接操作桌面
- 如果 DeskPilot 主服务是 Session 0，需要通过 desktop_agent（Session 1，端口 18765）转发执行
- 参考已有的 M6.5 双进程架构（backend + desktop_agent），消息发送器应运行在 desktop_agent 侧
- 剪贴板操作使用 ctypes（GlobalAlloc/GlobalLock/SetClipboardData），不要用 PowerShell Set-Clipboard（中文乱码）

### 2.4 配置

在 `config/deskpilot.yaml` 新增配置段：
```yaml
pm_messenger:
  enabled: true
  # 豆包窗口标题关键词
  doubao_window_keyword: "豆包"
  # 对话快捷键映射
  hotkeys:
    PM: "^1"     # Ctrl+1
    TP: "^2"     # Ctrl+2
    DP: "^3"     # Ctrl+3
  # 发送后等待时间（毫秒）
  send_delay_ms: 500
  # 审计日志保留天数
  audit_retention_days: 30
```
