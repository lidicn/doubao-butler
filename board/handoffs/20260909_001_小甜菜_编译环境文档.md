## 二、具体需求

在 `E:\NAS\xiaotiancai\docs\` 目录下创建 `编译环境搭建.md`，包含以下内容：

### 1. 环境要求
- 操作系统：Windows 10/11
- JDK 版本（如 JDK 17）
- Android Studio 版本（或命令行工具）
- Android SDK 路径（TP 提供实际路径）
- Gradle 版本
- minSdk / targetSdk（电视端通常 minSdk 21+）

### 2. 安装步骤
- JDK 安装与环境变量配置
- Android SDK 安装（命令行工具方式，不需要完整 Android Studio）
- SDK Platform 版本（TP 提供）
- Build Tools 版本（TP 提供）
- Gradle 安装或使用 wrapper

### 3. 环境变量
- `JAVA_HOME`
- `ANDROID_HOME` / `ANDROID_SDK_ROOT`
- `PATH` 配置

### 4. 编译命令
- Debug 编译：`./gradlew assembleDebug`
- Release 编译：`./gradlew assembleRelease`
- 安装到电视：`adb install -r app/build/outputs/apk/debug/app-debug.apk`
- 查看日志：`adb logcat`

### 5. 电视型号与兼容性
- 目标电视/盒子型号（TP 提供）
- Android 版本（TP 提供）
- 分辨率（TP 提供，如 1920x1080）
- 硬件特性（是否有 USB 摄像头、HDMI 输入等，TP 提供）

### 6. 常见问题
- SDK 许可证接受
- Gradle 下载慢的镜像配置
- ADB 连接电视的方法（网络 ADB）
- 电视端开发者选项开启方法

### 7. Arcface FaceID 依赖说明
- FaceID 复用 TVPilot 子项目 Arcface（路径：D:\Documents\WorkSpace\TV_CAM\Arcface）
- 小甜菜如何集成 Arcface（是作为 module 依赖，还是通过 AIDL/IPC 调用 TVPilot 服务）
- 这部分需要跟 TP 确认后补充
