## 二、当前状态

### 已完成能力

**工具层（v0.2）**：12 个标准化工具
- 原子：screenshot / foreground / keyevent / tap / swipe / input_text / launch_app / wait
- mytv：zap / current / channels
- 系统：health

**组合动作（v0.3）**：
- combo_go_home（回桌面 + 前台验证）
- combo_search_play（飞牛搜索 + 中文输入 + 播放）
- ensure_mytv_foreground（已在 zap 内部实现）

**联调支撑（v0.3）**：
- tvremoteime 中文输入（广播接收器设置剪贴板）
- 操作存档 JSONL（ops.jsonl）+ /api/history 查询
- request_id 全链路贯穿
- 统一响应包络 + 标准化错误码

**无障碍服务（v0.4）**：
- Arcface App 内 A11yHttpServer（端口 8081），控件级操作
- TVPilot 代理 /api/a11y/* 端点

**智能状态识别（v0.5）**：
- /api/ocr — 截图 OCR 文字识别（返回文字+位置）
- /api/ui_state — 界面状态分类（首页/搜索页/播放页/设置页/弹窗/加载中）
- /api/play_state — 播放状态检测（播放/暂停/缓冲/广告）
- /api/screenshot_smart — 智能截图（自动裁剪+分辨率压缩）

**系统状态聚合（v0.6）**：
- /api/system_state — 电视系统状态（音量/网络/存储空间/前台 App）
- 音频控制（音量调节/静音切换）
- 无障碍增强

**IPTV & EPG 代理（v0.7）**：
- /iptv/source.m3u — 广东电信 IPTV 97 频道源代理（8 组分类，本地文件优先）
- /iptv/epg.xml — EPG 节目单代理（51zmt 源，频道名映射 CCTV1→中央一台，6 小时缓存）
- go2rtc 音频修复：97 频道全部 exec:ffmpeg 模式，MP2→AAC 转码，解决 HLS 无声音问题

**用户管理 / FaceID（v0.7）**：
- /api/users — 用户配置管理（GET 列表 / POST 创建更新）
- /api/users/switch?user= — 切换用户，自动同步 mytv 收藏列表
- MQTT 订阅 tv/livingroom/face — Arcface 人脸识别事件自动触发用户切换（5 秒去重）
- 用户配置持久化 /app/data/user_profiles.json

**mytv 保活**：heal_loop 每 60 秒巡检 mytv HTTP，不可达时自动 am start 拉起

**与豆包管家联调**：✅ 已通过（2026-09-08，4 场景 + 错误码重试矩阵 + 操作存档对账，5 项核心验收 4 项全绿 1 项部分通过）
