**版本**：v1.3.1
**更新日期**：2026-09-09
**维护者**：豆包管家 PM
**适用对象**：TVPilot、DeskPilot、小甜菜 等生态链子项目

| 项 | 值 |
|---|---|
| 服务地址 | `http://192.168.2.200:8095` |
| Web 界面 | `http://192.168.2.200:8095/`（账号 <redacted>/<redacted>） |

## 二、Bark 推送接口

供子项目推送通知到家长手机（iOS Bark App）。

### 2.1 推送消息

`POST /api/bark/push`

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| body | string | 是 | 推送内容 |
| title | string | 否 | 标题，默认"豆包管家" |
| role | string | 否 | 角色名，自动加标题前缀（如【小爱】） |
| level | string | 否 | `active`(默认) / `timeSensitive` / `critical` |
| url | string | 否 | 点击跳转 URL |
| group | string | 否 | 通知分组 |

**示例**：

```bash
curl -X POST http://192.168.2.200:8095/api/bark/push \
  -H "Authorization: Bearer <redacted>" \
  -H "Content-Type: application/json" \
  -d '{"body":"设备掉线：客厅电视","title":"设备告警","role":"小爱","level":"timeSensitive"}'
```

### 2.2 配置状态

`GET /api/bark/status` — 查看 Bark 是否配置（不泄露 key）

## 三、TTS 语音播报接口

统一语音播报，支持角色音色、房间/设备指定。

### 3.1 统一播报

`POST /api/tts/speak`

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| text | string | 是 | 播报文本 |
| role | string | 否 | 角色名（决定音色+前缀） |
| room | string | 否 | 目标房间（匹配该房间第一个启用设备） |
| device_id | string | 否 | 直接指定设备（优先级高于 room） |
| voice | string | 否 | 显式指定 edge-tts 音色（最高优先级） |
| title | string | 否 | 自定义播报前缀 |
| no_prefix | bool | 否 | 不加前缀，默认 false |

**角色音色映射**：

| 角色 | 音色 | 头像 | 定位 |
|---|---|---|---|
| 豆包管家 | zh-CN-XiaoxiaoNeural（晓晓） | 蓝系机器人 | 默认，温暖女声 |
| 小爱 | zh-CN-XiaoyiNeural（晓伊） | 粉系少女 | 家庭设备管理员，活泼少女 |
| 小甜菜 | zh-CN-XiaohanNeural（晓涵） | 橙系少女 | 开发助理，温柔女声 |
| lidicn | zh-CN-YunxiNeural（云希） | 紫系 | 成熟男声 |
| kevin | zh-CN-YunyangNeural（云扬） | 蓝系 | 少年男声 |
| emily | zh-CN-XiaomoNeural（晓墨） | 粉系 | 儿童女声 |

> 角色音色独占：选了即锁定，其他角色不可用同一音色。Bark 推送时自动带角色头像。

**可用房间与设备**：

| 房间 | 设备 ID | 类型 |
|---|---|---|
| 客厅 | tv_living | 电视 |
| 客厅 | xiao_living | 小米音箱（左） |
| 客厅 | xiao_living_right | 小米音箱（右） |
| 书房 | xiao_study | 小米音箱 |
| Kevin房间 | xiao_kevin | 小米音箱 |
| Emily房间 | xiao_emily | 小米音箱 |
| 主卧室 | xiao_touch8 | 小米触屏音箱 |
| 主卧室浴室 | xiao_master_bath | 小米音箱 |
| 卫生间 | xiao_toilet | 小米音箱 |

> **注意**：客厅有多个设备，用 `room: "客厅"` 会匹配到电视。要播到客厅音箱请用 `device_id: "xiao_living"`。

**播放通道**（按优先级自动选择）：
1. **小米直连**（推荐）：管家合成 edge-tts 音频 → 小米云端 `player_play_music` 播放 → 轮询 position/duration → `player_play_operation stop` 精确停止。无循环、无截断、音色可控。需要 micoapi token 有效。
2. **HA media_player 兜底**：当小米直连 token 失效时自动回退。用 HA `media_player.play_media` 播放。X08A 等固件会单曲循环，HA stop 无效。
3. **电视**：管家合成 edge-tts 音频后 `tv.play_url` 播放。

> **重要**：小米直连需要 HA xiaomi_miot 集成的 micoapi token 有效。token 过期后需在 HA 重新登录小米账号刷新。token 失效时自动回退兜底路径（能出声但可能循环）。

**示例**：

```bash
# 书房音箱，小爱角色
curl -X POST http://192.168.2.200:8095/api/tts/speak \
  -H "Authorization: Bearer <redacted>" -H "Content-Type: application/json" \
  -d '{"text":"该休息了","role":"小爱","room":"书房"}'

# 客厅左音箱，豆包管家角色
curl -X POST http://192.168.2.200:8095/api/tts/speak \
  -H "Authorization: Bearer <redacted>" -H "Content-Type: application/json" \
  -d '{"text":"测试播报","role":"豆包管家","device_id":"xiao_living"}'
```

### 3.2 引擎信息

`GET /api/tts/engines` — 查看 TTS 引擎配置和角色音色映射

### 3.3 旧版试听（兼容）

`POST /api/tts/try` — 合成后播放到电视（建议改用 /api/tts/speak）

## 七、任务看板接口（PM 协作）

供 TP/DP 上报任务状态，供 PWA 看板展示。

### 7.1 上报任务状态

`POST /api/tasks/report`

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| task_id | string | 是 | 工单编号（如 TASK-20260908-001） |
| project | string | 是 | 项目名（TVPilot/DeskPilot/小甜菜） |
| status | string | 是 | `accepted`/`in_progress`/`completed`/`failed`/`blocked` |
| note | string | 否 | 备注说明 |
| reporter | string | 否 | 上报者 |

### 7.2 任务列表

`GET /api/tasks` — 获取所有任务（支持 ?project= & ?status= 过滤）

### 7.3 任务详情

`GET /api/tasks/{task_id}` — 获取单个任务及状态流转历史

## 十二、调用注意事项

1. **鉴权**：所有接口都需要 `Authorization: Bearer <redacted>` Header。
2. **编码**：中文内容请确保 UTF-8 编码。PowerShell 中 `Invoke-RestMethod -Body` 中文会乱码，建议用 Python 或 `curl.exe` + 文件。
3. **Bark 网络**：当前 Bark 用局域网 IP，手机在局域网外可能收不到。Tailscale 通道修复后自动切换。
4. **小米音箱音色**：当前通过 HA notify 播报，音色由音箱决定，role 的 voice 参数暂不影响音箱实际音色（只影响前缀和电视端）。
5. **重试策略**：调用失败建议重试 3 次，间隔 5 秒。连续失败记录日志并上报看板。
6. **版本兼容**：旧版 `/api/tts/try` 保留兼容，新开发请用 `/api/tts/speak`。
